# Writer v3 paired benchmark

This directory records the writer snapshot/cache follow-up against both the
pre-regression baseline `e8849a86` and the release-branch base `2b9b4e22`.

`paired_perf.py` runs every observation in a fresh process pinned to one CPU.
Each of 21 pairs reverses A/B order on alternating rounds and is followed by a
current/current A/A control. Reported changes are medians of paired percentage
changes; confidence intervals are 50,000-draw paired bootstrap intervals.

The measured operations are `write_con_shared`, `write_columns`, and
`write_extxyz`. `raw-e8849a86.json` and `raw-2b9b4e22.json` contain every
observation and the complete protocol metadata. The corresponding Markdown
tables are generated by the same command and are not hand-transcribed.

`perf-stat-current.json` is the raw JSON-lines output for one pinned
`write_con_shared` observation. Software counters were available; hardware
cycle and instruction counters were reported as unsupported by this VM.
