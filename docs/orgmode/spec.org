* Specification

- Version :: 3.1 (major 3, minor 1)
- Date :: 2026-10-11
- Status :: Stable
- Reference implementation :: [[https://github.com/lode-org/readcon-core][readcon-core]]
- Surface grammar :: =grammar/readcon.pest= (quoted in the appendix; not the hot path)
- Clause index :: =docs/orgmode/clauses.tsv=, emitted by =scripts/emit_clauses.py=
- In-memory API :: [[file:implementation-notes.org][implementation notes]] (informative for this format)

This document is the normative CON format. CON checkpoints come from
rare-event work on eOn

Requirement words follow [[https://www.rfc-editor.org/rfc/rfc2119][RFC 2119]].
Each normative requirement has an id =CON-<section>.<n>=.
Where this prose and the quoted PEG disagree, these clauses win.

- CON-status.1 :: MUST :: A reader MUST accept the version number of every minor of major 3, including minor 0 and unknown minors.
- CON-status.2 :: MUST :: A new implementation MUST accept version 2 and implicit version 1.

* File
:PROPERTIES:
:CUSTOM_ID: file
:END:

A file is a concatenation of frames. Extensions: =.con=, =.convel=,
and the compression envelopes =.con.gz=, =.convel.gz=, =.con.zst=,
=.convel.zst=.

- CON-file.1 :: MUST :: A CON file MUST be UTF-8.
- CON-file.6 :: MUST NOT :: A CON file MUST NOT begin with a byte-order mark.
- CON-file.2 :: MUST :: Parsers MUST accept LF (=\n=) and CRLF (=\r\n=) line endings.
- CON-file.3 :: MUST :: Parsers MUST ignore trailing spaces and tabs on every line.
- CON-file.4 :: MUST :: Labels MUST be compared case-insensitively after collapsing each run of spaces to one space.
- CON-file.5 :: MUST NOT :: Writers MUST NOT insert an extra blank line between frames.

* Frame and end of file
:PROPERTIES:
:CUSTOM_ID: frame
:END:

Each frame is a 9-line header, one coordinate block per atom type, then
the declared sections. There is no inter-frame marker.

- CON-frame.1 :: MUST :: After the last complete frame, lines that contain only whitespace MUST be ignored.
- CON-frame.2 :: MUST NOT :: Readers MUST NOT silently drop a partial last frame.
- CON-frame.3 :: MUST :: One to eight header lines of a further frame MUST be reported as =IncompleteHeader=.
- CON-frame.4 :: MUST :: Fewer coordinate rows than the header declares MUST be reported as =IncompleteFrame=.
- CON-frame.5 :: MUST NOT :: A blank line followed only by whitespace to end of file MUST NOT be read as a legacy velocity block.
- CON-frame.6 :: MUST :: A partial declared section MUST be reported as =IncompleteSection(name)=.

* Header

| Line | Content                                      |
|------+----------------------------------------------|
|    1 | Free-form generator text, preserved          |
|    2 | One JSON object, or free text for version 1  |
|    3 | Three lengths a, b, and c, in angstrom       |
|    4 | =alpha beta gamma= in degrees                |
|    5 | Free-form text, preserved                    |
|    6 | Free-form text, preserved                    |
|    7 | Type count, integer >= 1                     |
|    8 | Per-type counts, each an integer >= 1        |
|    9 | One mass per type, in amu                    |

Line 1 and lines 5-6 have no semantics.

- CON-header.1 :: MAY :: Writers MAY leave lines 5 and 6 empty.
- CON-header.2 :: MUST :: Parsers MUST preserve line 1 and lines 5 and 6.

** Line 2: Metadata
:PROPERTIES:
:CUSTOM_ID: metadata
:END:

Line 2 is one JSON object when the file is version 2 or newer.
A line that does not start with ={= after trimming is implicit version 1.
Metadata is line 2. Line numbers count from 1.

- CON-line2.1 :: MUST :: A line 2 that starts with ={= MUST be one UTF-8 JSON object and nothing else.
- CON-line2.2 :: MUST :: Malformed JSON on that line MUST be rejected.
- CON-line2.3 :: MUST :: A JSON object that omits =con_spec_version= MUST be rejected.
- CON-line2.4 :: MUST :: =con_spec_version= MUST be a JSON number, the major version, not a string.
- CON-line2.5 :: MUST :: JSON =con_spec_version= 0 or 1 MUST be rejected as =UnsupportedVersion=.
- CON-line2.6 :: MUST :: An unknown major MUST be rejected as =UnsupportedVersion=.
- CON-line2.7 :: MUST :: A reader of a known major MUST accept the version number of every minor of that major, including minors it does not implement.
- CON-line2.8 :: MUST :: Unknown keys MUST be preserved on rewrite.
- CON-line2.9 :: MUST :: =con_spec_minor=, when present, MUST be a JSON integer >= 0.
- CON-line2.10 :: MUST :: A missing =con_spec_minor=, or an explicit 0, MUST mean minor 0.
- CON-line2.11 :: MUST :: =sections=, when present, MUST be an array of strings.
- CON-line2.12 :: MUST :: =validate=, when present, MUST be a boolean.
- CON-line2.13 :: MUST :: Reserved keys MUST use the types in this document.

** Cell
:PROPERTIES:
:CUSTOM_ID: cell
:END:

Line 3 is =|a| |b| |c|=. Line 4 is =alpha= =angle(b,c)=, =beta= =angle(a,c)=,
=gamma= =angle(a,b)=, in degrees. The conventional Cartesian placement puts
=a= along x and =b= in the xy plane
(=client/ConFileIO.cpp= cell write and read in eOn 3.6.0; ASE =cellpar_to_cell=).
=lattice_vectors= is three row vectors in angstrom, =[a, b, c]=.

- CON-cell.1 :: MUST :: When =lattice_vectors= is present, readers MUST prefer it over lines 3-4.
- CON-cell.2 :: MUST :: A writer that emits =lattice_vectors= MUST write lines 3-4 consistent with that matrix at the precision the writer is using.
- CON-cell.3 :: MUST :: A missing =pbc= key MUST be read as periodic in all three directions.
- CON-cell.4 :: MUST :: =pbc=, when present, MUST be a length-3 array of booleans.
- CON-cell.5 :: MUST :: =lattice_vectors=, when present, MUST be three length-3 arrays of finite numbers.

** Counts

- CON-count.1 :: MUST :: The type count and each per-type count MUST be integer tokens >= 1.
- CON-count.2 :: MUST :: A zero type count, a zero per-type count, or a frame with no atoms MUST be rejected as =InvalidCount= in every mode.
- CON-count.3 :: MUST NOT :: A frame with zero atoms MUST NOT be written. It is not representable.
- CON-count.4 :: MUST :: The coordinate blocks MUST follow header order.
- CON-count.6 :: MUST :: The total atom count MUST equal the sum of line 8.
- CON-count.5 :: MUST :: Component numbers in labels MUST start at 1.

* Coordinates

One block per type: a symbol line, a =Coordinates of Component N= label,
then one atom line per atom of that type. Columns are whitespace-separated.

| Column | Token   | Meaning                                      |
|--------+---------+----------------------------------------------|
|      1 | float   | x, angstrom                                  |
|      2 | float   | y, angstrom                                  |
|      3 | float   | z, angstrom                                  |
|      4 | integer | Constraint flag                              |
|      5 | integer | Atom id, optional                            |

** Per-direction constraints (column 4)
:PROPERTIES:
:CUSTOM_ID: constraints
:END:

Column 4 is an integer token. Bit 0 is x, bit 1 is y, bit 2 is z.
Spec 1 (no JSON on line 2): 0 is free, 1 is fixed in all three directions.
Spec 2 and later: 0 through 7 are the bitmask, and 1 is x only.
Writers of spec 2 and later emit 7 for all-fixed.

- CON-mask.1 :: MUST :: Column 4 MUST be an integer token with no sign and no decimal point.
- CON-mask.2 :: MUST :: In spec 1, readers MUST treat 0 as free and 1 as fixed on x, y, and z.
- CON-mask.3 :: MUST :: In spec 1, any other column-4 token MUST be =InvalidFixedFlag=.
- CON-mask.4 :: MUST :: In spec 2 and later, values 0 through 7 MUST be read as the bitmask above.
- CON-mask.5 :: MUST :: A float spelling, a sign, or a value outside the legal set MUST be =InvalidFixedFlag= in every mode, including when =validate= is absent or false.
- CON-mask.6 :: MUST NOT :: A spec 2 or later writer MUST NOT emit 1 to mean all-fixed.
- CON-mask.7 :: MUST :: A spec 2 or later writer MUST emit 7 for an atom fixed on x, y, and z.

** Atom index (column 5)
:PROPERTIES:
:CUSTOM_ID: atom-index
:END:

Column 5 is the atom id. No base is implied. Grouping by type reorders
atoms relative to a pre-group sequence. eOn keeps file order when ids
repeat, and uses unique ids as that pre-group sequence
(=client/ConFileIO.cpp= matter order in eOn 3.6.0).

- CON-id.1 :: MUST :: Column 5, when present, MUST be parsed as an integer in 0 through 2^64-1, never through binary64.
- CON-id.2 :: MUST NOT :: Readers MUST NOT assume that ids start at 0 or at 1.
- CON-id.3 :: MUST :: Writers MUST emit ids that are unique within the frame.
- CON-id.4 :: MUST :: Readers MUST accept repeated ids.
- CON-id.8 :: MUST :: Readers MUST keep file order when ids repeat and when they do not.
- CON-id.5 :: MUST NOT :: Readers MUST NOT reorder atoms by id.
- CON-id.6 :: MUST :: When the ids in a frame are unique, those ids MUST record the pre-grouping order.
- CON-id.7 :: MUST :: A 4-column atom line MUST use the 0-based position of that atom in the frame as its id.

* Sections
:PROPERTIES:
:CUSTOM_ID: sections
:END:

A section is present exactly when its name is in =sections=.
An empty =sections= array means no section follows, and it disables the
legacy velocity fallback. With no =sections= key, one blank line that
begins a complete velocity block is a velocity section. That fallback
is the only undeclared section, and =CON-frame.5= limits it.

** Section declaration

- CON-section.1 :: MUST :: On disk, a section MUST be treated as present exactly when its name is listed in =sections=, aside from the legacy velocity fallback.
- CON-section.2 :: MUST :: Exactly one blank line MUST precede each section block.
- CON-section.3 :: MUST NOT :: Writers MUST NOT put a blank line between the component blocks inside a section.
- CON-section.4 :: MUST :: Each component block MUST be a symbol line, a label =<Name> of Component N=, and one data row per atom of that type.
- CON-section.5 :: MUST :: The per-atom energy section name MUST be =energies=.
- CON-section.6 :: MUST NOT :: =atom_energies= MUST NOT be used as a section name.
- CON-section.7 :: MUST :: An unknown section name MUST be reported as =UnknownSection= when the frame minor is not newer than the minor this reader implements.
- CON-section.8 :: MAY :: When the frame minor is newer than the reader implements, the reader MAY skip an unknown section whose row token count is given by =section_arity=.
- CON-section.9 :: MUST :: If that minor is newer and =section_arity= does not give the row token count, the reader MUST report =UnknownSection=.
- CON-section.10 :: MUST :: Adding a reserved section name MUST increase =con_spec_minor=.
- CON-section.16 :: MUST NOT :: Adding a reserved section name MUST NOT require a new major.
- CON-section.11 :: MUST :: =section_arity=, when present, MUST be an object mapping section names to integers >= 1, each the exact token count on a data row.

| Name            | Label                         | Row                                      |
|-----------------+-------------------------------+------------------------------------------|
| =velocities=    | =Velocities of Component N=   | =vx vy vz= flag id                       |
| =forces=        | =Forces of Component N=       | =fx fy fz= flag id                       |
| =energies=      | =Energies of Component N=     | energy flag id                           |
| =charges=       | =Charges of Component N=      | charge flag id                           |
| =spins=         | =Spins of Component N=        | spin flag id                            |
| =magmoms=       | =Magmoms of Component N=      | =mx my mz= flag id                       |
| =displacements= | =Displacements of Component N=| =dx dy dz= flag id, angstrom            |
| =spreads=       | =Spreads of Component N=      | =sx sy sz= flag id, angstrom, each >= 0 |

Vector rows have three numeric fields. Scalar rows have one.
Identity columns repeat the coordinate flag and id.
0 in a =spreads= row is a classical point.

- CON-section.12 :: MAY :: When =validate= is not true, readers MAY ignore an identity-column mismatch after the row has the right number of fields.
- CON-section.13 :: SHOULD :: The =energy= metadata value SHOULD equal the sum of the =energies= rows.
- CON-section.14 :: MUST NOT :: A mismatch between that sum and =energy= MUST NOT reject the frame.
- CON-section.15 :: MUST :: Each =spreads= value MUST be finite and >= 0.

** Validation mode
:PROPERTIES:
:CUSTOM_ID: validation-mode
:END:

- CON-validate.1 :: MUST :: =validate= true MUST add the checks in =CON-validate.3=.
- CON-validate.4 :: MUST NOT :: =validate= true MUST NOT relax a check that already applies in every mode.
- CON-validate.2 :: MUST :: When =validate= is true, =sections= MUST be present, and an empty array is legal.
- CON-validate.3 :: MUST :: In that mode, readers MUST reject a bad reserved-key type, a non-positive cell length, an angle outside (0, 180) degrees, a non-positive mass, a coordinate label that does not match, an unrecognized symbol other than =X=, a section label or symbol mismatch, or an identity column that does not match the coordinate row, as =ValidationError=.

** Frame topology (bonds)
:PROPERTIES:
:CUSTOM_ID: bonds
:END:

=bonds= is optional frame topology, not a section.
Each entry is =[i, j]= or ={"i": i, "j": j}= with an optional integer =order=.
Indices are 0-based into coordinate-block order, not column-5 ids.
This key is legal on major 3. It does not change the major.

- CON-bonds.1 :: MUST NOT :: =bonds= MUST NOT appear in =sections=.
- CON-bonds.2 :: MUST :: With =validate= true, a malformed =bonds= entry MUST be rejected.
- CON-bonds.3 :: MUST :: With =validate= false, unknown =bonds= shapes MUST be preserved.

* Units (required)
:PROPERTIES:
:CUSTOM_ID: units
:END:

=units= maps a dimension to a unit expression: names combined with =*=, =/=, =^=, and parentheses.
Version 3 requires =length= and =energy=.
Velocity is length/time taken from =units=.

The natural time unit used by eOn and by ASE, verified by an eOn 3.6.0 round trip, is written exactly =(amu*angstrom^2/eV)^0.5=.
That expression is a time. =units.rs= parses it as about 10.180505710759414 fs.
eOn hard-codes 10.1805055 fs (=include/eon/ParametersOptions.h=).
The relative difference is about 2e-8.
A writer that canonicalises the expression by inserting spaces is not using the pinned spelling.

- CON-units.1 :: MUST :: Major 3 MUST include =units.length= and =units.energy= as non-empty strings of the matching dimension.
- CON-units.2 :: MUST :: Optional =mass=, =time=, =velocity=, and =force= strings, when present, MUST have the matching dimension.
- CON-units.3 :: MUST :: A writer of minor 1 or later MUST write =units.time= whenever the frame has a velocities section.
- CON-units.4 :: MUST NOT :: A writer MUST NOT insert =time: fs= silently when the frame does not carry a time unit.
- CON-units.5 :: MUST :: The natural unit MUST be written with the exact spelling =(amu*angstrom^2/eV)^0.5=.
- CON-units.6 :: MUST :: Version 1 and version 2 files carry no =units=. Their velocities MUST be read in the natural unit.
- CON-units.7 :: MUST :: A major-3 file with minor 0 MUST be read with velocities in the natural unit.
- CON-units.12 :: MUST NOT :: A =time= label on a major-3 minor-0 file MUST NOT be trusted.
- CON-units.8 :: MUST :: From minor 1 onward, =units.time= MUST be authoritative for velocities.
- CON-units.9 :: MUST :: An invalid unit expression on write MUST be reported as =InvalidUnits=.
- CON-units.10 :: MUST NOT :: Writers MUST NOT replace an invalid unit with a default.
- CON-units.11 :: MAY :: A consumer MAY apply an explicit velocity time-unit override when a file breaks =CON-units.6= through =CON-units.8=.

Minor 0 is the v3.0 rule because the producers of those velocity sections wrote natural-unit numbers under a =fs= label.

* Numbers
:PROPERTIES:
:CUSTOM_ID: numbers
:END:

- CON-num.1 :: MUST :: Readers MUST reject NaN, Inf, Infinity, and the signed and mixed-case spellings of those words, in every numeric field and in every mode, as =NonFiniteValue=.
- CON-num.2 :: MUST NOT :: =validate= true MUST NOT be required before a reader applies =CON-num.1=.
- CON-num.9 :: MUST NOT :: =validate= true MUST NOT accept a non-finite value.
- CON-num.3 :: MUST NOT :: The C ABI absent-value NaN sentinel MUST NOT be written to a file. It is specified in the implementation notes.
- CON-num.4 :: MUST :: Readers MUST convert a finite decimal token to binary64 with correct rounding.
- CON-num.5 :: MUST :: A conforming writer in its default mode MUST write each finite float so that parsing it returns the same binary64 (=FloatFormat::RoundTrip=).
- CON-num.6 :: MUST :: Fixed-decimal output MUST be used only when the writer is asked for it, and it need not round-trip.
- CON-num.7 :: MUST :: A token that is not a decimal number and not a non-finite spelling MUST be =InvalidNumberFormat=.
- CON-num.8 :: MUST :: A row with the wrong number of fields MUST be =InvalidVectorLength=.

eOn =.convel= output at 6 digits after the decimal (=kConvelPrecision= in =client/ConFileIO.cpp=) is fixed-decimal and lossy.
A measured kinetic-energy loss for that rounding is 5.8e-7 relative.

A float token is an optional =+= or =-=, a significand with at least one digit, an optional fraction (a leading dot is allowed), and an optional exponent. An integer token is one or more ASCII digits and nothing else.

* Compression
:PROPERTIES:
:CUSTOM_ID: compression
:END:

- CON-compress.1 :: MUST :: A gzip envelope MUST expose every member of a multi-member file, in order, as CON text.
- CON-compress.2 :: MUST :: A zstd envelope MUST expose every frame in the stream as CON text.
- CON-compress.3 :: SHOULD :: Readers SHOULD detect gzip and zstd by magic bytes, not only by the extension.

* Errors

Line numbers count from 1. Metadata failures are line 2.
=IncompleteSection= carries the section name.

| Class                      | When                                                         |
|----------------------------+--------------------------------------------------------------|
| =NonFiniteValue=           | NaN, Inf, or a spelling of either, any mode                  |
| =InvalidFixedFlag=         | Column 4 is not a legal integer flag, any mode               |
| =InvalidCount=             | Type count, per-type count, or atom count is not >= 1        |
| =InvalidUnits=             | Unit expression is missing, mistyped, or the wrong dimension |
| =IncompleteHeader=         | Fewer than 9 header lines remain for a started frame         |
| =IncompleteFrame=          | A coordinate block is shorter than declared                  |
| =IncompleteSection(name)=  | A declared section is missing or short                       |
| =InvalidNumberFormat=      | A token is not a decimal number                              |
| =InvalidVectorLength=      | A row has the wrong number of fields                         |
| =UnknownSection=           | A section name is not known and cannot be skipped            |
| =UnsupportedVersion=       | Unknown major, or JSON major 0 or 1                          |
| =ValidationError=          | A =validate= true check failed                               |

- CON-error.1 :: MUST :: Each class in the table MUST be distinguishable by a caller.
- CON-error.2 :: MUST :: Reported line numbers MUST count from 1, with metadata on line 2.

* Version history

| Version | Date       | Change                                                                 |
|---------+------------+------------------------------------------------------------------------|
|       1 | original   | eOn text. Column 5 present. Column 4 is 0 or 1. No JSON.              |
|       2 | 2026-03-25 | JSON line 2, ids, bit masks, declared sections.                       |
|     3.0 | 2026-06-27 | =units.length= and =units.energy= required. Minor absent.             |
|     3.1 | 2026-10-11 | Minor 1. =units.time= when velocities are present. Natural-unit rule. |

Normative changes on 2026-10-11, by decision:

- Non-finite numbers are rejected in every mode (=D1=).
- A partial last frame is an error. Trailing whitespace is not a frame. A blank line and then only whitespace is not a velocity block (=D2=).
- A section is present exactly when its name is in =sections=. Builder clearing is not a format rule (=D3=).
- Counts are integers >= 1. Zero atoms are =InvalidCount= (=D4=).
- One blank line before a section, and none between its component blocks (=D5=).
- The scalar energy section is =energies= (=D6=).
- =bonds= is specified for major 3 (=D7=).
- Column 4 is an integer flag, with spec-1 and spec-2 meanings (=D8=).
- Column 5 is an integer id. Readers keep file order (=D9=).
- Velocity units follow the version rules, and the natural spelling is pinned (=D10=).
- Invalid units fail the writer (=D11=).
- Lines 3-4 and =lattice_vectors= follow the cell convention. Missing =pbc= is fully periodic (=D12=).
- Default float text round-trips binary64. Fixed decimals are opt-in (=D13=).
- Unknown keys are kept. Unknown sections of a newer minor may be skipped by =section_arity= (=D14=).
- The major stays 3. =con_spec_minor= is 1. A same-major reader accepts every minor's version number (=D15=).
- Gzip members and zstd frames are normative envelopes (=D16=).
- Line 2 is one JSON line. Trailing space is ignored. Labels collapse spaces (=D17=).

The media type =chemical/x-con= is informative, as is =text/plain; charset=utf-8=.
CON has no magic bytes. Identify a file by extension and by this header.

* Token grammar
:PROPERTIES:
:CUSTOM_ID: tokens
:END:

- CON-token.1 :: MUST :: Integer tokens MUST match one or more ASCII digits, with no sign and no decimal point.
- CON-token.2 :: MUST :: Float tokens MUST be finite decimals. A leading sign, a leading dot, and an exponent are allowed. Non-finite spellings are =CON-num.1=, not floats.
- CON-token.3 :: MUST :: The separators inside a line MUST be spaces or tabs.
- CON-token.4 :: MUST :: The quoted PEG is informative surface syntax. A reader MUST follow this document when the PEG allows a token these clauses reject.

* Appendix: quoted PEG

The following is =grammar/readcon.pest= as of this specification.
A conformance change owns edits to that file.

#+begin_example
// CON / convel surface syntax (PEG / Pest).
//
// Aligns with docs/orgmode/spec.org (CON v2–v3). This grammar defines the
// *syntactic* shape of one or more concatenated frames. Semantic rules
// (atom counts matching header N_i, Component index order, JSON metadata
// keys, fixed-mask values, validate=true geometry) are enforced by the
// reference implementation in src/parser.rs — not by this PEG alone.
//
// Hot-path I/O does not depend on Pest; this file is the formal grammar
// artifact shipped with the repo, validated in tests via the optional
// `grammar` feature / dev-dependencies.
//
// Section row arities (spec §sections):
//   vector: velocities, forces, magmoms, displacements, spreads  →  v0 v1 v2 fixed [atom_id]
//   scalar: energies, charges, spins     →  value fixed [atom_id]

/// One or more frames, no inter-frame marker (frames are concatenated).
file = { SOI ~ frame+ ~ EOI }

/// Header + per-type coordinate blocks + optional section blocks.
frame = { header ~ type_block+ ~ section* }

/// Nine-line header (lines 1–9 of the specification).
header = {
    free_line ~ NL
    ~ free_line ~ NL
    ~ float3_line
    ~ float3_line
    ~ free_line ~ NL
    ~ free_line ~ NL
    ~ integer_line
    ~ integer_list_line
    ~ float_list_line
}

/// Free-form line (generator comment, JSON metadata, or reserved text).
/// Does not consume the trailing newline.
free_line = { (!NL ~ ANY)* }

float3_line = { ws* ~ float ~ ws+ ~ float ~ ws+ ~ float ~ ws* ~ NL }

integer_line = { ws* ~ integer ~ ws* ~ NL }

integer_list_line = { ws* ~ integer ~ (ws+ ~ integer)* ~ ws* ~ NL }

float_list_line = { ws* ~ float ~ (ws+ ~ float)* ~ ws* ~ NL }

/// One chemical-type block: symbol, "Coordinates of Component k", atom lines.
type_block = {
    symbol_line ~ NL
    ~ coord_label ~ NL
    ~ vector_atom_line ~ (NL ~ vector_atom_line)*
    ~ NL?
}

symbol_line = { ws* ~ symbol ~ ws* }

/// Element / type symbol (letters, optional trailing digits/underscore).
symbol = @{ ASCII_ALPHA ~ (ASCII_ALPHANUMERIC | "_")* }

/// Wire labels may use legacy "component" casing (e.g. eOn sulfolene fixtures).
/// Pest ^string is case-insensitive ASCII.
coord_label = {
    ws* ~ ^"Coordinates of Component" ~ ws+ ~ integer ~ ws*
}

/// Coordinate / 3-vector section row: v0 v1 v2 fixed_mask [atom_id]
vector_atom_line = {
    ws* ~ float ~ ws+ ~ float ~ ws+ ~ float
    ~ ws+ ~ integer
    ~ (ws+ ~ integer)?
    ~ ws*
}

/// Scalar section row: value fixed_mask [atom_id]
scalar_atom_line = {
    ws* ~ float
    ~ ws+ ~ integer
    ~ (ws+ ~ integer)?
    ~ ws*
}

/// Backward-compatible alias used by tests and older notes.
atom_line = { vector_atom_line }

/// Optional section: blank separator + homogeneous type blocks (vector or scalar).
/// After a type_block's trailing newline, one more newline is the blank line
/// required by the specification before a section.
section = {
    ws* ~ NL
    ~ (section_type_block_vector+ | section_type_block_scalar+)
}

section_type_block_vector = {
    symbol_line ~ NL
    ~ section_label_vector ~ NL
    ~ vector_atom_line ~ (NL ~ vector_atom_line)*
    ~ NL?
}

section_type_block_scalar = {
    symbol_line ~ NL
    ~ section_label_scalar ~ NL
    ~ scalar_atom_line ~ (NL ~ scalar_atom_line)*
    ~ NL?
}

section_kind_vector = { ^"Velocities" | ^"Forces" | ^"Magmoms" | ^"Displacements" | ^"Spreads" }
section_kind_scalar = { ^"Energies" | ^"Charges" | ^"Spins" }

/// Union of all section kinds (docs / tests).
section_kind = { section_kind_vector | section_kind_scalar }

section_label_vector = {
    ws* ~ section_kind_vector ~ ws+ ~ ^"of Component" ~ ws+ ~ integer ~ ws*
}

section_label_scalar = {
    ws* ~ section_kind_scalar ~ ws+ ~ ^"of Component" ~ ws+ ~ integer ~ ws*
}

/// ASCII decimal float (optional sign, fraction, scientific exponent).
float = @{
    "-"?
    ~ ASCII_DIGIT+
    ~ ("." ~ ASCII_DIGIT*)?
    ~ (("e" | "E") ~ ("+" | "-")? ~ ASCII_DIGIT+)?
}

integer = @{ "-"? ~ ASCII_DIGIT+ }

ws = _{ " " | "\t" }
NL = _{ "\r\n" | "\n" }
