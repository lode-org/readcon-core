#+TITLE: CPC manuscript (readcon-core)

The source of truth is =src/rg_main.org=.
Do not hand-edit =src/rg_main.tex=.
Tables and figures are written by =scripts/gen_tables.py= from committed CSV files.

* Build

From the repository root:

#+begin_src bash
cargo build --release --manifest-path paper/cpc/bench/readcon-bench/Cargo.toml
python paper/cpc/scripts/hcn_case.py
python paper/cpc/bench/run_bench.py
python paper/cpc/bench/analyze_bench.py
pixi r cpc-tex
#+end_src

=pixi r cpc-tex= regenerates the tables, checks =highlights.txt= and the abstract length, exports the org file, and builds the PDF.

* Benchmark

=paper/cpc/bench/run_bench.py= times readcon-core against ASE, chemfiles XYZ, MDAnalysis H5MD, and h5py.
Each cell is 30 repeats, interleaved baseline then peer.
Timeouts and reader failures stay in =bench/results/repeats.csv=.
=paper/cpc/bench/analyze_bench.py= writes medians, BCa intervals, and the Holm column.

* Claims

=claims.org= lists behavioural sentences, the specification clause, the test, and the status on this tree.
