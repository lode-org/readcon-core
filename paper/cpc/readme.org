#+TITLE: CPC manuscript (readcon-core)

The source of truth is =src/rg_main.tex= and =src/rg_supp.tex=.
=src/rg_main.org= predates the shortened manuscript and is kept only for its long-form methods text; do not export it over the TeX files.
Tables and figures are written by =scripts/gen_tables.py= from the CSV files under =data/= and =bench/results/=.

* Build

Build the supplement first so the main text can resolve its cross-references, then the main text, twice:

#+begin_src bash
cd paper/cpc/src
for i in 1 2; do latexmk -pdf rg_supp.tex; latexmk -pdf rg_main.tex; done
python3 ../scripts/check_manuscript.py
#+end_src

The older org route follows.

From the repository root, with the generated macros already written:

#+begin_src bash
emacs -nl --script paper/cpc/scripts/org2tex.el paper/cpc/src/rg_main.org
#+end_src

=org2tex.el= checks the abstract length and =highlights.txt=, exports the org file, and runs latexmk.
=pixi r cpc-tex= is the same sequence when pixi is available.
Regenerate the tables first with =python3 paper/cpc/scripts/gen_tables.py=.

* Benchmark

=paper/cpc/bench/run_bench.py= times the Python binding of readcon-core at one worker against ASE, chemfiles XYZ, MDAnalysis H5MD, and h5py, each at one thread.
A second loop times 2, 4 and 8 workers against a fresh one-worker baseline on the ten thousand frame file.
Set =READCON_SRC= to the checkout that should be timed.
The host column is =bench-vm=.
Each comparison cell is 30 interleaved pairs.
Timeouts and reader failures stay in =bench/results/repeats.csv=.
=paper/cpc/bench/analyze_bench.py= writes medians, bias-corrected intervals, and the Holm column.
=paper/cpc/scripts/cases.py= builds the platinum slab with ASE fcc111 plus one hydrogen adsorbate, and it writes the kinetic-energy row from that slab's velocities.
=paper/cpc/scripts/hcn_case.py= rewrites the public HCN and HNC endpoints and records what each reader returns.
Those endpoints are the public files of doi:10.1016/j.mex.2026.103899.
