\caption{Both corpora on the frame readers and the frame count of the Python module and the C library.
A cell gives the reads that return the outcome of the manifest, of all reads at that thread setting.
The \cpathsFiles{} files are the \cpathsConformance{} of the conformance corpus and the \cpathsCorpusThreeOne{} of the CON 3.1 corpus.
A read matches when it gives the manifest's outcome and frame count, or its error class; neither binding reports a line, and where the manifest names no frame count every read of the file gives the same one.
The plain file is the corpus file; the mapped file is the decoded text at the mapping threshold or beyond, with legal \cpathsPadLines-line frames in front of a smaller text, or after a text rejected on its first line, which add their frames to the count; the gzip file is the decoded text compressed with gzip.
A Python str cannot hold the \cpathsNotText{} files that are not UTF-8, so \texttt{read\_con\_string} reads the others.
The C library has no zstd in either build and rejects the \cpathsZstdFiles{} zstd files in the plain file, file iterator and frame count rows with the message that names the feature, as it documents.
The default build has no Rayon and parses on one thread at every setting, and the release archives contain the parallel build.}
