\begin{abstract}
Rare-event campaigns restart from a text checkpoint.
CON is the frame eOn uses for minima, saddles, band images and restarts, and the frame ASE reads and writes.
That frame had no specification, so the two readers diverged.
CON 3.1 gives the frame a major version and a minor version.
A reader of the same major accepts a later minor, keeps an unknown metadata key, and may skip an unknown section whose width is declared.
The default printer emits text that parses back to the same binary64 value.
readcon-core 0.17.0 is the reference implementation.
One C interface serves the other languages, and eOn 3.6.0 reads CON through it.
An interrupted nudged elastic band, resumed from that printer, agrees with the uninterrupted band to \(1\times10^{-14}\,\text{\AA}\).
Six decimals move a coordinate by up to \(5\times10^{-7}\,\text{\AA}\).
On a Pt(100) hop, a height constraint read as a full freeze removes the imaginary mode while the barrier changes by \(1.4\times10^{-5}\,\mathrm{eV}\), so the harmonic prefactor is undefined.
A natural-unit velocity read as femtoseconds multiplies the kinetic energy by 103.64.
On a warm-cache file of 10{,}000 copies of one 218-atom frame, the Rust core reads at 1.34\,GB/s.

\textit{Nature of problem:}
Campaigns exchange geometries and resume from CON frames, which had no specification.
Readers therefore drop a per-axis mask, drop the atom id after the file has grouped atoms by element, mislabel the velocity time unit, or round coordinates to a fixed number of decimals.
The search that continues then runs under a different constraint, pairs a different atom with its image, or restarts from a different kinetic energy than the one that was stored.
\textit{Solution method:}
CON 3.1 names a major version and a minor version, and it states which later changes a reader of the same major must still accept.
Decimal fields are read with correct rounding, and the default writer emits the shortest text that parses back to the same binary64 value.
Six fixed decimals remain available when a caller asks for them.
One C interface sits over the Rust core, so that every binding shares a single parse, and eOn 3.6.0 reads through that path.
A multi-frame file is split by a serial scan of frame boundaries, after which each frame is parsed on its own and returned in file order.
gzip and zstd are envelopes around the same text.
\textit{Additional comments including restrictions and unusual features:}
The restart comparison is five steepest-descent steps on one Morse band, stopped at an iteration cap.
The limited-memory quasi-Newton history is absent from the frame, and a resume with that optimiser takes a different next step.
The velocity factor is an illustration: an eOn dynamics job redraws velocities and writes none.
The timed file repeats one 218-atom frame, on one processor with a warm cache.
Conversion of a frame that stores forces into ASE 3.29.0 atoms passes energy and forces positionally, which that ASE release accepts only as keywords.
A failed C read returns a null handle and does not classify the error.

\section{Introduction}
\label{sec:introduction}
Rare events in solids and molecules set the rates of diffusion, reaction and structural change.
Harmonic transition-state theory estimates such a rate from the barrier and from the curvatures at a minimum and at a first-order saddle \cite{eyringActivatedComplexChemical1935,vineyardFrequencyFactorsIsotope1957,hanggiReactionrateTheoryFifty1990}.
The stationary points come from the nudged elastic band, its climbing-image form and the string method, and from single-ended searches such as the dimer \cite{henkelmanMethodsFindingSaddle2005,jonssonNudgedElasticBand1998,henkelmanClimbingImageNudged2000,asgeirssonNudgedElasticBand2021,smidstrupImprovedInitialGuess2014,eStringMethodStudy2002,petersGrowingStringMethod2004,henkelmanDimerMethodFinding1999,heydenEfficientMethodsFinding2005,kastnerSuperlinearlyConvergingDimer2008,olsenComparisonMethodsFinding2004,walesExploringEnergyLandscapes2018,hermesAcceleratedSaddlePoint2019,hermesGeometryOptimizationSpeedup2021,hermesSellaOpensourceAutomationfriendly2022}.
When the event is too rare for a direct trajectory, the same landscape is reached by hyperdynamics, by other accelerated molecular dynamics, by adaptive kinetic Monte Carlo, and by parallel replicas \cite{voterHyperdynamicsAcceleratedMolecular1997,voterExtendingTimeScale2002,mironAcceleratedMolecularDynamics2003,henkelmanLongTimeScale2001,voterIntroductionKineticMonte2007,xuAdaptiveKineticMonte2008,novotnyMonteCarloAlgorithms1995,voterParallelReplicaMethod1998,perezLongtimeDynamicsThrough2016}.
Basin hopping and minima hopping propose the next minimum, so a campaign is a sequence of searches that stop \cite{walesGlobalOptimizationBasinhopping1997,goedeckerMinimaHoppingEfficient2004}.
Each stop begins from the geometry the previous search stored.
A queue, a public-resource client, or a distributed kinetic Monte Carlo rank may be the process that reads that geometry \cite{andersonBoincSystemPublicresource2005,pedersenDistributedImplementationAdaptive2010}.
eOn is the code in which this text became the working checkpoint \cite{chillEonSoftwareLong2014,rohitgoswamiTheochemuieonV3602026,goswamiEfficientExplorationChemical2025}.
A surrogate fitted inside the saddle loop still hands the same frame to the force evaluator \cite{goswamiEfficientImplementationGaussian2025,koistinenNudgedElasticBand2019,koistinenMinimumModeSaddle2020,petersonAccelerationSaddlepointSearches2016}.
The checkpoint is shared state, because another rank, another machine, or a Python hand-off may be the next reader \cite{pengReproducibleResearchComputational2011,inceCaseOpenComputer2012}.
The file has to mean the same thing after the code that wrote it has changed \cite{hinsenCaringYourData2012,hinsenDealingSoftwareCollapse2019}.
The Atomic Simulation Environment began as a scripting interface and reads and writes the same text \cite{bahnObjectorientedScriptingInterface2002,larsenAtomicSimulationEnvironmenta2017}.
The file itself was never specified, so the two readers diverged \cite{rohitgoswamiTheochemuieonV3602026}.

The divergence is concrete.
From version 2, column 4 is a per-axis mask, while ASE 3.29.0 turns any nonzero value into a full freeze and ignores the identity in column 5.
Six fixed decimals move a coordinate by up to \(5.0\times10^{-7}\,\text{\AA}\).
Velocities are stored in the natural unit \((\mathrm{amu}\cdot\text{\AA}^{2}/\mathrm{eV})^{0.5}\).
With \(1\,\text{\AA}=10^{-10}\,\mathrm{m}\), \(1\,\mathrm{fs}=10^{-15}\,\mathrm{s}\) and \(1\,\mathrm{eV}=1.602176634\times10^{-19}\,\mathrm{J}\), that unit equals \(10.1805\,\mathrm{fs}\) \cite{tiesingaCodataRecommendedValues2021,mckeeverUnitMeasurementLibraries2021}.
Producers of the 3.0 era labelled the natural-unit numbers fs, so a reader that honours the label scales the kinetic energy by \(103.64=(10.1805)^{2}\) \cite{rohitgoswamiTheochemuieonV3602026}.
A velocity Verlet step and a velocity-rescaling thermostat both advance those components, so the label travels with them \cite{swopeComputerSimulationMethod1982,bussiCanonicalSamplingThrough2007}.

This paper specifies that frame and reports the reader eOn 3.6.0 already calls.
The contribution is the versioned text, the shared conformance corpus, and the restart measurements, set beside a force call.
Section~\ref{sec:requirements} names the six fields a resumed search needs.
Section~\ref{sec:format} specifies the frame.
Section~\ref{sec:implementation} describes readcon-core 0.17.0.
Section~\ref{sec:validation} reports the corpus, the mask, and the interrupted band.
Section~\ref{sec:performance} reports the cost of the read.

\label{sec:requirements}

A surface calculation freezes buried atoms on every axis and often holds only the height of an adsorbate \cite{jonssonSimulationSurfaceProcesses2011}.
Harmonic transition-state theory builds the prefactor from the free modes, so an axis that was meant to move and is frozen removes a mode.
On the EMT Pt(100) slab in Section~\ref{sec:validation} the bottom nine atoms carry mask 7 and the adatom carries mask 4, so only \(z\) is held.
ASE 3.29.0 reads every nonzero mask as a full freeze.
The barrier of that symmetric hop barely moves, and the imaginary mode disappears.
The optimiser history is a separate loss.
Limited-memory quasi-Newton, the optimisers surveyed for saddle searches, and damped molecular dynamics such as FIRE keep a short history that a geometry frame does not store, so a resume can match the coordinates and still take a different next step \cite{nocedalUpdatingQuasinewtonMatrices1980,sheppardOptimizationMethodsFinding2008,bitzekStructuralRelaxationMade2006}.
Column 5 is the atom identity, kept on the row so a later frame can find the same atom after the file has grouped atoms by element \cite{gundeIraShapeMatching2021}.
A parallel-replica segment has the same need, since a dephased copy is the same atoms \cite{perezParallelReplicaDynamics2015}.

Line 1 is free text.
An empty first header line is kept.
Line 2 is one JSON object holding the version, the units, the periodicity and the section names \cite{brayJavascriptObjectNotation2017,langdaleParsingGigabytesJson2019}.
An empty second header line is implicit version 1.
Lines 3 and 4 are the cell lengths and the angles in degrees.
The type count, the per-type counts and the masses follow.
Coordinates are a symbol, the heading ``Coordinates of Component \(N\)'', and one row of \(x\), \(y\), \(z\), mask and id.
A blank line opens a later section.
Under version 1, line 2 is a comment and column 4 is only 0 or 1, so masks 7 and 4 cannot be stored as written.
On this listing, six decimals shift a coordinate by at most \(4.2\times10^{-7}\,\text{\AA}\) and an EMT energy by \(4.4\times10^{-7}\,\mathrm{eV}\).
Section~\ref{sec:supp-anatomy} counts the bytes in a 28-atom frame that carries velocities.

Lengths and angles rebuild the box with \(a\) along \(x\) and \(b\) in the \(xy\) plane,
\begin{equation}
\mathbf{a}=a\,\hat{\mathbf{x}},\qquad
\mathbf{b}=b\cos\gamma\,\hat{\mathbf{x}}+b\sin\gamma\,\hat{\mathbf{y}},
\end{equation}
after which \(\mathbf{c}\) is fixed by \(\alpha\) and \(\beta\) so the cell is right-handed \cite{bekkerUnificationBoxShapes1997}.
When line 2 carries lattice vectors, those three rows are the cell.
A missing periodicity flag means the cell is periodic on every axis.

From version 2, column 4 is the integer in Table~\ref{tab:mask}.
Mask 0 is free, mask 4 holds \(z\) only, and mask 7 holds every axis.
A float spelling, a sign, or a value outside that set is an illegal flag.
Column 5 is an integer from 0 through \(2^{64}-1\), read as an integer.
Writers emit ids unique in the frame.
A missing id column takes the zero-based row index.
This release returns file order.

\section{Reference implementation}
\label{sec:implementation}
readcon-core 0.17.0 is the reference reader and writer \cite{goswamiReadconcoreConconvelReaderwriter2026}.
Figure~\ref{fig:architecture} is the layering.
One Rust core sits behind a C interface, and C, C++, Python, Julia and Fortran callers sit on that waist.
Fortran 2008 reaches the same C symbols through its C interoperability, and Julia does so through its foreign-function interface \cite{bezansonJuliaFreshApproach2017}.
Decimal fields go through a correctly rounded conversion on that path \cite{lemireNumberParsingGigabyte2021,mushtakFastNumberParsing2023}.
The eOn C++ reader is this C++ wrapper \cite{rohitgoswamiTheochemuieonV3602026}.

\begin{figure}[ht]
\centering
\includegraphics[width=0.92\textwidth]{figures/generated/architecture.pdf}
\caption{Layering of the reference implementation.
The Rust core parses and writes CON.
The C interface is the waist every other caller uses, including the C++ wrapper that eOn 3.6.0 calls.}
\label{fig:architecture}
\end{figure}

The caller owns a frame handle and frees it.
Structure-of-arrays accessors return a pointer into that frame.
Absent numeric metadata is a NaN sentinel and is not written back.
The Rust core and the bindings name an error class: a missing version, malformed metadata, a non-finite number, an illegal flag, a bad count, an illegal unit, a short header, a short block, an unknown section, or an unsupported version.
The C bulk read returns a null handle, as Listing~\ref{lst:c} tests, and the class is not available on that path.
Section~\ref{sec:supp-errors} names the class the Python binding raises on each illegal file.

\begin{lstlisting}[language=C,caption={Reading every frame through the C interface. A failed read is a null handle. The energy accessor is NaN when the frame stores no energy.},label={lst:c}]
uintptr_t n = 0;
struct RKRConFrame **f = rkr_read_all_frames(path, &n);
if (f == NULL) { return 1; }
uintptr_t nxyz = 0;
const double *xyz = rkr_frame_xyz_f64(f[0], &nxyz);
double e = rkr_frame_energy(f[0]);
free_rkr_frame_array(f, n);
\end{lstlisting}

Listing~\ref{lst:py} is the Python read and the default write.
Six decimals are a separate argument.
The binding releases the interpreter lock while the core parses and takes it back to build one object per atom.
A caller who needs only coordinates can stay on the arrays \cite{harrisArrayProgrammingNumpy2020}.

\begin{lstlisting}[language=Python,caption={A round-trip write. The default printer preserves binary64. Six decimals are a separate argument.},label={lst:py}]
frames = readcon.read_con("slab.con")
readcon.write_con("rt.con", frames)
\end{lstlisting}

The reader records the byte offset where each frame starts, in the same spirit as an on-disk offset index for a trajectory \cite{gowersMdanalysisPythonPackage2016}.
The scan stays serial because each start depends on the counts of every frame before it.
Each task then parses its own slice, and the frames come back in file order.
A single frame stays one task.
Builds that include the parallel feature accept a worker count.
Zero follows the automatic policy, and one forces the sequential parse.
The wheels and the C archives are built with that feature.
The conformance files are the eighteen frames of Table~\ref{tab:corpus}, and each binding runs that list.
An optional ingress from other chemical files can link chemfiles \cite{frauxChemfileschemfilesVersion01042023}.
In this release, copying an ASE atoms object into a frame takes an id array when the caller has set one and otherwise numbers atoms in row order.
That copy does not write the velocity time unit, so a caller who has velocities must set the unit.
A frame that stores forces is handed to ASE through \texttt{SinglePointCalculator}.
This release passes the energy and the forces as positional arguments.
ASE 3.29.0 accepts those values only as keywords, so the conversion raises until the call is adapted.
Section~\ref{sec:supp-fidelity} states that adaptation and uses it for the format matrix.
The frame files in that matrix were not edited.

The precedent is a shared validation list such as checkCIF, which turns a format rule into an alert a later reader can reproduce \cite{spekCheckcifValidationAlerts2020,hallCrystallographicInformationFile1991}.
Table~\ref{tab:corpus} is the corpus: ten legal files and eight illegal files, run by the five bindings.
The C read reports that decision as a null handle.

The default printer reads the eOn checkpoint of the restart below back as the same bytes.
The six-decimal writer differs by at most \(5.0\times10^{-7}\,\text{\AA}\).
A separate probe keeps the public HCN coordinates, writes ids 2, 0 and 1, and sets an x-only mask on hydrogen \cite{vanmourikAbInitioGlobal2001,goswamiReproducibleOrchestrationBest2026}.
readcon-core returns that mask and those ids, and it keeps the declared natural time unit.
ASE 3.29.0 rejects the file once a velocity block is present.
On the coordinate frame it reports hydrogen frozen on every axis and stores no id.

For the EMT Pt(100) hop the bottom layer is fixed and the adatom is held in \(z\) only.
Each pair of endpoints was relaxed with BFGS to a force target of \(0.005\,\mathrm{eV}/\text{\AA}\), met at \(0.0028\,\mathrm{eV}/\text{\AA}\).
A climbing-image band of seven images with the improved tangent was converged to \(0.01\,\mathrm{eV}/\text{\AA}\) \cite{henkelmanClimbingImageNudged2000,henkelmanImprovedTangentEstimate2000}.
With the height held, the barrier is \(0.366598\,\mathrm{eV}\) on a path of \(2.90040\,\text{\AA}\).
One imaginary mode, \(-4.08\,\mathrm{meV}\), carries weight 0.987 on the lateral motion, and the Vineyard prefactor is \(3.24\times10^{10}\,\mathrm{Hz}\) \cite{vineyardFrequencyFactorsIsotope1957}.
That prefactor belongs to the constrained EMT Hessian.
It is separate from a measured rate of Pt self-diffusion on this face \cite{kelloggSurfaceSelfdiffusionPt0011990}.
ASE 3.29.0 freezes the adatom on every axis.
The frozen band, interpolated with the constraints ignored, converges to a barrier of \(0.366584\,\mathrm{eV}\) on a path of \(2.95955\,\text{\AA}\).
The saddle geometries differ by a minimum-image RMSD of \(7.78\times10^{-4}\,\text{\AA}\).
The energy change is \(1.4\times10^{-5}\,\mathrm{eV}\) because the straight line of this symmetric hop passes through the saddle.
The frozen image has no imaginary mode, so the harmonic prefactor is undefined.
A less symmetric hop would leave that line.
Figure~\ref{fig:asemask} places both bands on the \((s, d)\) plane \cite{goswamiTwodimensionalRmsdProjections2026}.

The restart runs an eOn 3.6.0 client with the Morse Pt potential on the same 28-atom slab, the bottom nine atoms at mask 7 \cite{rohitgoswamiTheochemuieonV3602026,goswamiEnhancedClimbingImage2026}.
The band has five movable images.
The optimiser is steepest descent, chosen because it stores no step history, so a difference after the load is a difference in the file.
Both the uninterrupted run and each resume take five steepest-descent steps and stop at that iteration cap.
The band has not converged.
The force at the last step is \(0.83265\,\mathrm{eV}/\text{\AA}\).
Giving the resume the same iteration cap as the uninterrupted job leaves it one step short, because the loaded band is written before the first step, and that unmatched pair differs by \(0.0068\,\mathrm{eV}\).
The matched comparison is the one reported here.
Both resumed runs reproduce the uninterrupted printed table: maximum force \(3.0658\), then \(1.2007\), then \(0.59762\,\mathrm{eV}/\text{\AA}\), and highest image \(0.8305\), then \(0.6911\), then \(0.6417\,\mathrm{eV}\).

After five steps the round-trip resume barrier is \(0.63493\,\mathrm{eV}\), a difference of 0 from the uninterrupted band.
The minimum-image displacement on that final band is at most \(8.9\times10^{-15}\,\text{\AA}\).
The six-decimal resume shifts the barrier by \(+1.0\times10^{-6}\,\mathrm{eV}\), with a minimum-image maximum of \(4.9\times10^{-7}\,\text{\AA}\).
The checkpoint round trip is bitwise exact.
The resumed band is not, because the search has taken steps after the load.
Figure~\ref{fig:restart} shows the three final bands.
Section~\ref{sec:supp-restart} shows the per-image displacement at each resumed step.

An L-BFGS resume, using eOn's default band optimiser, does not show that agreement.
Both printers resume to \(0.6707\,\mathrm{eV}\) against \(0.6336\,\mathrm{eV}\) for the uninterrupted ending, since the limited-memory history is absent from the frame and both files lose the same thing.
A dimer started from the round-trip geometry gives a saddle energy of \(-112.618941\,\mathrm{eV}\) and a curvature of \(-10.613681\), the same as the uninterrupted dimer \cite{rohitgoswamiTheochemuieonV3602026,goswamiEfficientExplorationChemical2025}.
Six decimals shift that saddle by \(-3.0\times10^{-6}\,\mathrm{eV}\).
The dimer also stops at its iteration cap.

On the same 28 atoms the kinetic energy is \(0.888\,\mathrm{eV}\) in the natural unit and \(92.02\,\mathrm{eV}\) if those components are misread as \(\text{\AA}/\mathrm{fs}\), a ratio of 103.64.

eOn's dynamics job redraws velocities and writes none, so this step is an illustration of the mislabelled unit, separate from the band comparison above \cite{rohitgoswamiTheochemuieonV3602026}.

\section{Performance}
\label{sec:performance}
The timings use one file on one Intel Xeon processor of family 6, model 207, with 8 hardware threads.
The bench binary was built with rustc 1.88 and the C++ wrapper with g++ 13.3, and the Python timings use Python 3.12.
The file is \(167.71\,\mathrm{MB}\): 10{,}000 copies of one 218-atom frame, read from a warm page cache.
Repeating one frame removes frame-to-frame variation from the rate.
It also means the rate is the cost of this frame, not a survey of production trajectories.
Native medians use 15 repeats, Python medians use 9, and the thread sweep uses 5.
An interval is a bias-corrected and accelerated 95 percent interval of that median \cite{efronBetterBootstrapConfidence1987,kaliberaRigorousBenchmarkingReasonable2013,mytkowiczProducingWrongData2009,hoeflerScientificBenchmarkingParallel2015}.
Table~\ref{tab:perf} and Figure~\ref{fig:layers} are the automatic policy and the one-thread parses.
The C++ column is the wrapper eOn calls \cite{rohitgoswamiTheochemuieonV3602026}.

The bias-corrected interval on that ratio runs from 0.815 to 0.993.

Copying the file to the null device on the hot cache takes \(0.0185\,\mathrm{s}\) (\(9.06\,\mathrm{GB/s}\)).
The automatic Rust parse, \(0.126\,\mathrm{s}\), is 6.8 times that copy.
Loading the bytes into a string takes \(0.0945\,\mathrm{s}\) (\(1.77\,\mathrm{GB/s}\)), and the boundary scan takes \(0.0344\,\mathrm{s}\) (\(4.87\,\mathrm{GB/s}\)).
Treating those two stages as a serial fraction of the \(0.484\,\mathrm{s}\) one-thread parse gives \(f=0.267\).

The measured speedup exceeds the Amdahl bound, so the string load and the boundary scan are not a pure serial fraction of the parallel parse.

The curve is that bound.

\section{Limitations}
\label{sec:limitations}
The specification describes a frame eOn and ASE already exchange.
It does not add a saddle method.
The mask result is one symmetric hop: the barrier changes by \(1.4\times10^{-5}\,\mathrm{eV}\) and the imaginary mode is lost, and no Vineyard rate is claimed for the frozen reading.
The steepest-descent restart is five steps of an unconverged Morse band.
The L-BFGS control is the production-shaped result, and it disagrees because the frame has no optimiser memory.
The velocity step is an illustration on a file eOn dynamics would not have written.
The throughput is one repeated frame, one processor, eight threads and a warm cache.
The Amdahl curve underestimates that sweep, and the paper reports the mismatch.
The C bulk read returns a null handle with no error class.
The Python plateau is the interpreter lock on this build.
ASE 3.29.0 rejects the positional energy and forces this release passes for a frame that stores forces.
A database of the five bands in the supplement returns 35 hashes for 35 images: the round-trip endpoints match in coordinates and differ in stored text, so the hash does not collapse them (Section~\ref{sec:supp-dedup}).

\section{Conclusions}
\label{sec:conclusions}
CON 3.1 specifies the text checkpoint that eOn and ASE exchange, including the per-axis mask, the atom identity and the velocity time unit \cite{rohitgoswamiTheochemuieonV3602026}.
readcon-core 0.17.0 is the reference implementation, and eOn 3.6.0 reads CON through it.
An interrupted steepest-descent band resumed from the default printer agrees with the uninterrupted band to \(1\times10^{-14}\,\text{\AA}\).
Six decimals move a coordinate by up to \(5\times10^{-7}\,\text{\AA}\).
On the timed file the core reads at 1.34\,GB/s.
The conformance corpus is what each binding runs against that specification.
