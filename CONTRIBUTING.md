# Contributing

Developer setup, commit conventions, testing, and release steps are in
[docs/orgmode/contributing.org](docs/orgmode/contributing.org).

The published HTML page is
[contributing.html](https://lode-org.github.io/readcon-core/contributing.html).

Pull requests do not re-record the generated C++ wrap pin. After each
merge, `develop` re-records the pin automatically.
